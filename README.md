## App Description
Workout Log is a planned app that will help users record their
workouts and keep track of their exercise routines. Users will be
able to enter exercises, record sets, repetitions, and weights,
and review their previous workouts. The goal is to make it easier
to stay organized and see progress over time.

For Assignment 1, the app displays only the title "Workout Log."

## Intended Users
This app is intended for gym beginners, students, and fitness
enthusiasts who want a simple way to organize and track their workouts.

## Planned Features
- Add workout entries with the date and exercise name.
- Record the sets, repetitions, and weight used for each exercise.
- View previous workouts in a workout history table.
- Filter workout history by exercise or date.

## How to Run
Install the required dependency:

    python -m pip install -r requirements.txt

Start the app:

    python -m streamlit run app.py
